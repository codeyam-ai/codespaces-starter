# CodeYam Editor in GitHub Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/codeyam-ai/codespaces-starter?quickstart=1)

Click the button to try the [CodeYam Editor](https://codeyam.com) with nothing
installed on your own machine. It runs in a GitHub codespace, a Linux machine
GitHub hosts for you and opens in your browser.

## What happens when you click it

1. **GitHub asks for your Anthropic API key.** It is stored as a Codespaces
   secret, so the build agent is signed in when the editor opens. You can skip
   it and sign in from inside the editor instead.
2. **The codespace installs everything.** That means the editor, the Claude
   Code CLI, and a browser for screenshots. The first time takes a few minutes.
3. **The editor opens in a new tab on the New Project screen.** Pick the AI
   that should build (Claude, if you gave an Anthropic key), then describe what
   you want to build. The editor builds it with you against a live preview.

This repository is intentionally almost empty: no app, no `.codeyam/`. Your
project is created inside the codespace the first time the editor starts.

## Keeping your work

A codespace made from this template is not connected to a repository of your
own yet. To keep what you build, open the codespace's **Source Control** panel
and choose **Publish to GitHub**. That creates a repository under your account.
This template is never changed.

## Good to know

- **Who can see the editor:** only you. GitHub keeps the editor's port private
  and asks you to sign in to GitHub before it lets anyone through. If you make
  the port public, the editor starts requiring its own one-time token.
- **Stopping and restarting:** your files are kept, and the editor comes back
  on the same address when the codespace restarts.
- **Skipped the key, or want to add it later:** open GitHub's
  **Settings → Codespaces → Secrets**, add `ANTHROPIC_API_KEY`, give this
  codespace's repository access to it, and rebuild the codespace.
- **Using Codex or Gemini instead of Claude:** add `OPENAI_API_KEY` or
  `GEMINI_API_KEY` the same way, then pick that agent in the editor.

## How this template is made

`.devcontainer/devcontainer.json` is generated by
`codeyam-editor editor devcontainer-setup` run in an empty directory. It is
not written by hand, so it matches what existing projects get. The editor
repository runs a drift check against it. To regenerate it, run that command
in an empty folder and copy the file here.

The codespace installs the editor from npm at the production `latest` tag. To
try unreleased builds, use
[`codeyam-ai/codespaces-starter-staging`](https://github.com/codeyam-ai/codespaces-starter-staging),
which is the same template rendered with `--channel staging`.
